PDC Oracle

Signed USD prices, fail closed.

The oracle is an off-chain signed feed that Trade and related tools can verify. PDC has no EVM contracts. A native on-chain oracle_update path is a later daemon track — not what Trade consumes today.

Open Oracle Prices API Methodology

FEED

GET /api/prices/usd

Trade-compatible book with a signature envelope, monotonic sequence, and verified status when the publisher accepts the snapshot.

SRC

CEX median and Trade book

BTC and majors use a primary CEX quorum. PDC uses the Trade open book against BTCX. CoinGecko and CoinMarketCap are backup only when a pair has no primary source.

AUTH

Ed25519 authenticity

Consumers can check the signature instead of trusting an unsigned HTTP body. Stale or invalid envelopes are rejected by design.

How it fits

Trade reads the feed. You can too.

Trade shows USD hints from this feed. Bridge limits may reference it. Anyone can call the public API and verify the envelope without an account.
