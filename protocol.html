Protocol

Mechanisms written into the PDC core.

The names below are the names in the code. The text says what each one hides or enables on this network.

01 · Stealth

Stealth addresses

An output pays a one-time address. The published wallet address does not appear on the chain as the receiver of the transfer.

02 · Ring

d/v-CLSAG

An input is signed together with decoys. The default set has 10 members. From hard fork 4 the mandatory set has 15.

03 · Amount

Commitments and Bulletproofs+

The amount stays in a Pedersen commitment. Zero-knowledge proofs show the transaction is valid without printing the number.

04 · Asset

Confidential assets

The asset id on a wallet transfer is blinded. An observer cannot tell PDC from a token issued on the same chain.

05 · Stake

Zarcanum

Hidden-amount proof of stake after height 100. Odds follow the stake. The balance stays in a commitment.

06 · Consensus

RandomARQ + PoS

PoW and PoS each target 120 seconds. Together they set a 60-second block target. A PoS run is capped at 21 in a row.
