Trade and Oracle

Swap on PDC. Price from a signed feed.

PDC Trade is the public UI for Ionic Swaps and marketplace offers on Privacy Data Coin. The PDC Oracle publishes signed USD prices that Trade and related tools can verify.

Open Trade Open Oracle

PDC Trade

Non-custodial swaps on the chain.

Trade sits on top of the wallet marketplace and Ionic Swap RPCs. Funds stay in the wallet path. There is no deposit account on the site.

SWAP

Ionic Swaps

Proposal and accept flows use the PDC wallet ionic_swap methods. Settlement is on-chain, not a custodial matching engine.

BOOK

Order book and offers

Open orders and marketplace offers go through the Trade API and the wallet marketplace RPCs. Pairs such as PDC/BTCX appear on the public UI.

BRIDGE

BTC ↔ BTCX

Trade surfaces the BTC bridge path for BTCX. Limits and USD references use the oracle feed where the UI shows them.

Public UI: trade.privacydatacoin.com. API base used by the UI: api.trade.privacydatacoin.com.

PDC Oracle

Signed USD prices, fail closed.

The oracle is an off-chain signed feed. PDC has no EVM contracts. A native on-chain oracle_update path is a later daemon track, not what Trade consumes today.

FEED

GET /api/prices/usd

Trade-compatible book with a signature envelope, monotonic sequence, and verified status when the publisher accepts the snapshot.

SRC

CEX median and Trade book

BTC and majors use a primary CEX quorum. PDC uses the Trade open book against BTCX. CoinGecko and CoinMarketCap are backup only when a pair has no primary source.

AUTH

Ed25519 authenticity

Consumers can check the signature instead of trusting an unsigned HTTP body. Stale or invalid envelopes are rejected by design.

Public host: oracle.privacydatacoin.com. Methodology: /methodology.
