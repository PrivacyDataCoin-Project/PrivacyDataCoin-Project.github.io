Mission

Value that does not file a report.

PDC is for sending coins, issuing a token, registering an alias, and staking without publishing a balance. There is no premine. Blocks are mined with RandomARQ and staked with Zarcanum. The desktop wallet, the daemon, and simplewallet ship from the public GitHub release.

Why PDC

A private payment, and the tools around it.

01

Private by default

Sender, receiver, amount, and asset type stay hidden on a wallet transfer. There is no privacy mode to turn on.

02

Two locks on the chain

RandomARQ mining and Zarcanum staking secure PDC together. A rewrite has to beat both, not only one.

03

Open to run

Anyone can mine, stake, or run a full node. There is no premine and no approval. A coinstake only has to age 10 blocks.

04

Nothing to filter on

A wallet transfer does not name the parties or the amount, so there is no public field to censor by.

05

Fungible

Coins do not carry a visible history. One PDC is not marked by where it has been.

06

In the core

Confidential assets, aliases, marketplace offers, ionic swaps, and integrated addresses are part of this chain. A normal address starts with Px.

Why default matters

A private option paints a target. A private default does not.

Privacy as a toggle

  • Most activity stays readable.
  • The few shielded transfers are easy to single out.
  • Choosing privacy becomes a signal of its own.

PDC wallet transfers

  • Sender, receiver, amount, and asset type are hidden together.
  • Every such transfer adds to the same anonymity set.
  • Using the wallet does not mark you as the exception.

On this network

What PDC ships.

These pieces are in the PrivacyDataCoin-Project/PDC tree and in the public release.

GUI

Desktop wallet

The Qt GUI sends, receives, and talks to the PDC core, including aliases and custom assets.

NODE

Node

The daemon speaks P2P on port 19121 and RPC on 19211. The seed in the source is 169.58.142.131.

CLI

simplewallet

The command-line wallet is in the same release archives as the daemon.

ASSET

Confidential assets

A token issued here is blinded on transfer. The wallet whitelist is api.privacydatacoin.com — including BTCX for Trade.

ALIAS

Aliases

A short name can stand in for an address. The registration fee is burned.

OFFERS

Marketplace offers

On-chain offers the wallet and Trade can list or cancel. Settlement for matched trades uses ionic swaps — funds stay on the wallet path, not in a site account.

Trade and Bridge

Swap on PDC. Wrap Bitcoin.

Trade is the public non-custodial UI. Bridge mints and burns BTCX 1:1 with BTC. Settlement is ionic swap on-chain.

TRADE

PDC Trade

Order book and Easy Swap on trade.privacydatacoin.com. Companion signs; the site never holds a deposit account.

BRIDGE

BTC ↔ BTCX

Deposit BTC to mint BTCX, or burn BTCX to withdraw BTC. Live mins, fees, and pause flags come from Bridge status on the Trade API.

Short answers

From the repository, not from a brochure.

Is the supply capped?

No. get_base_block_reward returns 1 PDC at every height. There is no premine. About 1,440 blocks fit in a day when the 60-second target holds, so emission is about 525,600 PDC a year.

Which software should I run?

Use the files from the latest GitHub release of PrivacyDataCoin-Project/PDC. Hard fork 8 at height 50,000 needs build 11 or newer.

Where is the code?

The chain, the daemon, simplewallet, and the Qt desktop GUI live at github.com/PrivacyDataCoin-Project/PDC on the master branch.

Where are the docs?

docs.privacydatacoin.com
